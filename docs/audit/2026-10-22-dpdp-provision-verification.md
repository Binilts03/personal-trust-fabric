# DPDP provision verification — 2026-10-22

Independent check of every statutory claim in the DPDP vertical and the DPDP
privacy/launch material, against the primary text. Read-only audit: no source
file was changed.

## Scope and method

Files checked:

- `docs/verticals/dpdp-consent-gateway.md` (provision-mapping table, prose, transcript)
- `examples/dpdp-consent-gateway.mjs`
- `docs/privacy/dpdp.md`
- DPDP statements in `README.md`, `docs/launch/*.md`

Method: every claim traced to the instrument that owns it. Law-firm summaries
were used only to locate primary documents, never as authority. Statutory text
was read from the Gazette prints hosted by MeitY (the Act) and MeitY (the
Rules); the India Code mirror of the Act was unavailable from this environment
(see "Could not verify").

## Compliance-language check

   difference is the stderr tail.
